הקישורים של הגרסאות המלאות (עברית, רוסית, אנגלית, ילדים, מאמן) נמצאים בקובץ **`LINKS.md`** בתיקיית הפרויקט במחשב שלך — **בכוונה לא כאן.** הקובץ הזה עולה ל-GitHub והמאגר ציבורי.

⚠️ **חשוב להבין:** ההגנה של "קישור שאי אפשר לנחש" עובדת רק מול מי שלא יודע את הכתובת. מי שנכנס למאגר ב-GitHub רואה את שמות הקבצים. זה מספיק טוב ללקוחות פרטיים; אם תגיע ללקוח עסקי שדורש הגנה אמיתית — צריך לעבור לאחסון עם מאגר פרטי (למשל Netlify / Cloudflare Pages, בחינם).

## 🤝 איך מוכרים בפועל (שלב-אחר-שלב)

1. **התחל מהיכרות, לא מזרים.** פנה קודם לאנשים שאתה/משפחתך מכירים — מאמן, מורה, בעל עסק. שיווק קר בהודעות = אחוזי הצלחה נמוכים ותדמית ספאם.
2. **הובל עם ערך, לא עם מכירה.** שלח את **קישור ההדגמה** ותשאל שאלה פתוחה — לא "תקנה", אלא *"בניתי כלי לניהול תקציב, אשמח לשמוע מה דעתך"*.
3. **הקשב וזהה צורך.** אם הם מתעניינים — הצע גרסה ממותגת **שלהם** (שמם, צבעים, לוגו).
4. **הצע הצעה פשוטה.** מחיר אחד ברור + מה כלול. בלי הרבה אפשרויות מבלבלות.
5. **מסור רק אחרי תשלום.** את הקישור המלא — רק כשקיבלת את הכסף. (כקטין — עדיף דרך חשבון של הורה: Bit / PayBox / העברה.)
6. **תראה ללקוח איך להתקין** (ראה למטה) — זה הרגע שבו זה מרגיש "אפליקציה אמיתית" ולא "קישור".
7. **עקוב אחרי.** מי שלא ענה — תזכורת מנומסת אחת אחרי כמה ימים.

## 📲 איך הלקוח מתקין את זה (שלח לו את זה כמו שהוא)

**במחשב (Chrome / Edge):**
1. פתח את הקישור שקיבלת.
2. בשורת הכתובת, בצד, יש אייקון קטן של **התקנה** (מחשב עם חץ) — לחץ עליו, ואז "התקן".
3. האפליקציה נפתחת בחלון משלה ומופיעה בתפריט התחל / בשולחן העבודה. מעכשיו לא צריך את הקישור.

**בטלפון:**
- **אנדרואיד (Chrome):** תפריט ⋮ → "הוסף למסך הבית".
- **אייפון (Safari):** כפתור השיתוף → "הוסף למסך הבית".

עובד גם בלי אינטרנט. הנתונים נשמרים במכשיר בלבד.

> **לך (לא ללקוח):** אחרי שאתה מעדכן את האתר, GitHub שומר את הדף הישן עוד עד **10 דקות**. אל תיבהל אם הלקוח (או אתה) רואה גרסה ישנה מיד אחרי עדכון.

## ✅ מה כלול במכירה (מה הלקוח מקבל)

- כל הפיצ'רים של הגרסה שלו: תקציב חודשי, טבלת מעקב לפי קטגוריה עם פירוט הוצאות (נושא / סכום / תאריך), השוואה לחודש קודם, היסטוריה חודשית, ייצוא/ייבוא.
- הנתונים נשמרים אצל המשתמש בלבד — פרטי ובטוח.

## ❓ מענה להתנגדויות נפוצות

- **"יש אפליקציות חינם."** → נכון, אבל זו ממותגת **בשמך**, בלי הרשמות ובלי פרסומות, עובדת אופליין, והנתונים נשארים פרטיים. זה כלי מקצועי שלך, לא אפליקציה גנרית.
- **"זה מסובך?"** → בכלל לא — פותחים קישור ומתחילים. אין הורדות ואין חשבון. אפשר להתקין בלחיצה אחת.
- **"מה עם האבטחה?"** → אין שרת ואין איסוף מידע. הכל נשמר במכשיר של המשתמש בלבד.
- **"ואם אני מחליף מחשב?"** → ייצוא לקובץ JSON בלחיצה, וייבוא במחשב החדש.

## 🛠️ ליצירת גרסה חדשה / שינוי מיתוג

1. הקוד המקורי ב-`src/` (`index.html`, `style.css`, `app.js`). **לא לערוך את קבצי ה-HTML בשורש** — הם תוצרי בנייה ונדרסים.
2. מוסיפים בלוק קונפיג ב-`build.py` (ברשימת `EDITIONS`, או כ-`build(...)` נפרד) ומריצים:

```bash
python build.py
```

3. דוחפים לשני המאגרים:

```bash
git push origin master && git push fresh master
```

### ⚠️ כלל ברזל: לא משנים שם של קובץ שכבר נמסר ללקוח
אפליקציה מותקנת שומרת את הכתובת המקורית לנצח. אם הקובץ משנה שם — האפליקציה של הלקוח מקבלת 404 ומתה. אם חייבים — בונים את הגרסה גם בשם הישן (כמו שנעשה ב-`EDITIONS`).

### אפשרויות הקונפיג (`window.BUDGET_CONFIG`)

| שדה | מה זה עושה |
|------|-----------|
| `name` | שם האפליקציה (מופיע גם כשם האפליקציה המותקנת) |
| `tagline` | משפט תיאור |
| `logo` | אימוג'י לוגו (בעיצובים הבוגרים מוחלף אוטומטית במונוגרמה) |
| `accent` | `{ primary, primary2 }` — צבעי המותג |
| `preset` | קטגוריות: `generic` / `kids` / `coach` |
| `variant` | זהות עיצובית: `kids` / `coach` / **`dash`** (סרגל צד) / **`report`** (דוח מודפס) / **`mono`** (מסוף נתונים) |
| `lang` | שפת ממשק: `he` (ברירת מחדל) / `ru` / `en` |
| `tableOnly` | `true` = רק טבלת התקציב (הגרסאות ברוסית/אנגלית) |
| `showTable` | `true` = בגרסה העברית, מציע למשתמש לבחור בין טבלה לתנועות |
| `noEmoji` | `true` = מסיר את כל האימוג'ים + טבלה בסגנון ספר-חשבונות + פונטים Inter / IBM Plex Mono. **חובה** יחד עם `dash` / `report` / `mono` |
| `defaultTheme` | `"light"` / `"dark"` — ברירת מחדל אם המשתמש לא בחר בעצמו |
| `kids` | `true` = לוח מדליות + טון ידידותי |
| `brandedBy` | שם העסק/המאמן בתחתית |
| `demoLock` | `true` = גרסת הדגמה נעולה |
| `contact` | פרטי קשר לבאנר הרכישה |
| `hideDemo` | מסתיר את כפתור "טען נתוני הדגמה" |
| `storeKey` | מרחב שמות נפרד ל-localStorage. **כל לקוח = storeKey משלו**, אחרת שתי גרסאות באותו דומיין יחלקו נתונים |
