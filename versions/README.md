## 👥 למי מוכרים (קהלי יעד)

1. **מאמנים פיננסיים / יועצים** — רוצים כלי ממותג לתת ללקוחות שלהם.
2. **מורים / רכזי חינוך פיננסי / תוכניות נוער** — גרסת הילדים ככלי לימודי בכיתה.
3. **הורים** — כלי לילדים ללמוד לנהל דמי כיס.
4. **עסקים קטנים / עצמאים** — מעקב הוצאות פשוט בלי אקסל.

**טיפ:** בחר **קהל אחד** להתחיל איתו. עדיף להתמקצע מאשר לפזר.

## 💰 כמה לגבות (טווחים ריאליים)

המוצר סטטי — **אין עלויות שרת/תחזוקה**, אז זו מכירה חד-פעמית נקייה.

| מה | טווח מחיר | הערות |
|----|-----------|-------|
| גרסה ממותגת בסיסית (שם + צבעים + לוגו) | **₪150–₪350** | שינוי קונפיג + שליחת קובץ/קישור |
| גרסה מותאמת (קטגוריות מיוחדות, טקסטים, מיתוג מלא) | **₪350–₪800** | עבודת התאמה אמיתית |
| תוכנית חינוכית / בית ספר (גרסה + הסבר/הדרכה קצרה) | **₪500–₪1,500** | ערך גבוה יותר, קונה מוסדי |
| תוספת: עדכונים/שינויים עתידיים | **₪80–₪150** לפעם | אופציונלי |

**כלל אצבע להתחלה:** גרסה ממותגת פשוטה ב-**₪199** זה מחיר קל להגיד עליו "כן". אחרי כמה לקוחות — תעלה.

> 💡 מוכרים **ערך**, לא קוד. הלקוח לא קונה "אתר", הוא קונה כלי ממותג בשמו שחוסך לו זמן ונראה מקצועי.

## 🤝 איך מוכרים בפועל (שלב-אחר-שלב)

1. **התחל מהיכרות, לא מזרים.** פנה קודם לאנשים שאתה/משפחתך מכירים — מאמן, מורה, בעל עסק. שיווק קר בהודעות = אחוזי הצלחה נמוכים ותדמית ספאם.
2. **הובל עם ערך, לא עם מכירה.** שלח את **קישור ההדגמה** ותשאל שאלה פתוחה — לא "תקנה", אלא *"בניתי כלי לניהול תקציב, אשמח לשמוע מה דעתך"*.
3. **הקשב וזהה צורך.** אם הם מתעניינים — הצע גרסה ממותגת **שלהם** (שמם, צבעים, לוגו).
4. **הצע הצעה פשוטה.** מחיר אחד ברור + מה כלול. בלי הרבה אפשרויות מבלבלות.
5. **מסור רק אחרי תשלום.** את הקובץ/קישור המלא — רק כשקיבלת את הכסף. (כקטין — עדיף דרך חשבון של הורה: Bit / PayBox / העברה.)
6. **עקוב אחרי.** מי שלא ענה — תזכורת מנומסת אחת אחרי כמה ימים.

## ✅ מה כלול במכירה (מה הלקוח מקבל)

- קובץ HTML אחד (או קישור) — עובד בכל דפדפן, במחשב ובטלפון, **בלי התקנה**.
- ממותג בשמו: שם, צבעים, לוגו, קטגוריות מותאמות.
- כל הפיצ'רים: הכנסות/הוצאות, תקציב, תקציב לפי קטגוריה, יעדי חיסכון, גרפים, תובנות, ייצוא/ייבוא, דוח PDF.
- הנתונים נשמרים אצל המשתמש בלבד — פרטי ובטוח.

---

## ❓ מענה להתנגדויות נפוצות

- **"יש אפליקציות חינם."** → נכון, אבל זו ממותגת **בשמך**, בלי הרשמות ובלי פרסומות, עובדת אופליין, והנתונים נשארים פרטיים. זה כלי מקצועי שלך, לא אפליקציה גנרית.
- **"זה מסובך?"** → בכלל לא — פותחים קישור ומתחילים. אין הורדות ואין חשבון.
- **"מה עם האבטחה?"** → אין שרת ואין איסוף מידע. הכל נשמר במכשיר של המשתמש בלבד.

## 🛠️ ליצירת גרסה חדשה / שינוי מיתוג

עורכים את `build.py` (בלוק הקונפיג של הגרסה) ומריצים:

```bash
python build.py
```

אפשרויות הקונפיג (`window.BUDGET_CONFIG`):

| שדה | מה זה עושה |
|------|-----------|
| `name` | שם האפליקציה |
| `tagline` | משפט תיאור |
| `logo` | אימוג'י לוגו |
| `accent` | `{ primary, primary2 }` — צבעי המותג |
| `preset` | קטגוריות: `generic` / `kids` / `coach` |
| `variant` | זהות עיצובית מלאה: `kids` / `coach` |
| `kids` | `true` = לוח מדליות + טון ידידותי |
| `brandedBy` | שם העסק/מאמן בתחתית |
| `demoLock` | `true` = גרסת הדגמה נעולה |
| `contact` | פרטי קשר לבאנר הרכישה |
| `storeKey` | מרחב שמות נפרד ל-localStorage |

---

*כל הנתונים נשמרים במכשיר המשתמש בלבד — ללא שרת, ללא הרשמה, ללא עלויות תחזוקה.*
