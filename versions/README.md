# גרסאות ממותגות — מדריך מכירה והתאמה

כל הגרסאות בנויות מ**אותו קוד מקור** (`index.html`, `style.css`, `app.js`) עם קונפיגורציית מיתוג שונה.
זהו יתרון מכירה: מוצר אחד → אינסוף מותגים. כדי לייצר גרסה חדשה או לשנות מיתוג — עורכים את `build.py` ומריצים `python build.py`.

## הגרסאות הקיימות

| קובץ | מיתוג | קהל יעד |
|------|--------|----------|
| `../standalone.html` | **התקציב שלי** 💰 | כללי — כל אחד |
| `kids.html` | **הכסף שלי** 🐷 (ורוד/כתום, מדליות, קטגוריות ילדים) | תוכניות חינוך פיננסי, בתי ספר, הורים |
| `coach.html` | **מאמן פיננסי** 📊 (טורקיז, קטגוריות מקצועיות, מיתוג המאמן) | מאמנים פיננסיים, יועצים, רו"ח |

## אפשרויות הקונפיגורציה (`window.BUDGET_CONFIG`)

| שדה | מה זה עושה |
|------|-----------|
| `name` | שם האפליקציה (כותרת + לוגו) |
| `tagline` | משפט תיאור מתחת לשם |
| `logo` | אימוג'י הלוגו |
| `accent` | `{ primary, primary2 }` — צבעי המותג (גרדיאנט) |
| `preset` | סט קטגוריות: `generic` / `kids` / `coach` |
| `kids` | `true` מפעיל לוח הישגים/מדליות וטון ידידותי |
| `brandedBy` | שם עסק/מאמן שמופיע בתחתית (white-label) |
| `storeKey` | מרחב שמות נפרד ל-localStorage (כדי שגרסאות לא יתנגשו) |

## איך למכור למאמן (דוגמה)

1. פותחים `build.py`, בבלוק של `coach.html` משנים את `brandedBy` לשם הלקוח (למשל `"ישראל ישראלי · מאמן פיננסי"`) ואת `accent` לצבעי המותג שלו.
2. מריצים `python build.py`.
3. שולחים ללקוח את הקובץ `coach.html` — קובץ אחד, עובד בכל דפדפן, בלי התקנה.

> כל הנתונים נשמרים במכשיר של המשתמש בלבד — ללא שרת, ללא הרשמה, ללא עלויות תחזוקה.
