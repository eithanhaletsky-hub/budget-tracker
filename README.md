# 💰 התקציב שלי — מעקב הוצאות והכנסות

אפליקציית ווב פשוטה ונוחה למעקב אחרי הוצאות והכנסות אישיות, ניהול תקציב חודשי, וצפייה בגרפים וסטטיסטיקות.

**ללא AI, ללא API, ללא שרת, ללא הרשמה.** כל הנתונים נשמרים אך ורק בדפדפן שלך, במכשיר שלך.

## ✨ תכונות

- ➕ **הוספת הכנסות והוצאות** בקלות, עם קטגוריות, תיאור ותאריך
- 🏷️ **קטגוריות מובנות** (מזון, תחבורה, דיור, בילויים, משכורת ועוד) עם אייקונים וצבעים
- 🔍 **חיפוש וסינון** לפי סוג, קטגוריה או טקסט חופשי
- 📊 **גרפים** — פילוח הוצאות לפי קטגוריה (גרף עוגה) ומגמת 6 החודשים האחרונים (גרף עמודות)
- 🎯 **תקציב חודשי** — הגדרת יעד חודשי עם מד התקדמות והתראה על חריגה
- 📅 **ניווט בין חודשים** — כל חודש בנפרד עם הסיכומים שלו
- 🌙 **מצב כהה / בהיר**
- 📤 **ייצוא וייבוא** — גיבוי הנתונים לקובץ JSON, וייצוא לאקסל (CSV)
- 📱 **רספונסיבי** — עובד יפה בטלפון ובמחשב
- 🇮🇱 **עברית מלאה** עם כיוון RTL

## 🔒 פרטיות

האפליקציה לא שולחת שום מידע לאף שרת. הכל רץ מקומית בדפדפן ונשמר ב-`localStorage`.
כדי לא לאבד נתונים (למשל אם מנקים את הדפדפן) — מומלץ לייצא גיבוי מדי פעם.

## 🚀 הרצה

לא צריך התקנה. פשוט פותחים את `index.html` בדפדפן.

או, להרצה עם שרת מקומי פשוט:

```bash
python -m http.server 8130
```

ואז נכנסים ל־`http://localhost:8130`.

## 🛠️ טכנולוגיות

HTML, CSS ו-JavaScript טהור (Vanilla). ללא ספריות חיצוניות, ללא תלויות. הגרפים מצוירים ב-Canvas.
